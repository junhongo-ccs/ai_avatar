### チャンク識別子の選び方

Difyは識別子が出てくるたびに必ず切り、短い断片をまとめません。最大長を超えた断片だけが、さらに長さで切られます。

- **Q&A（`---`）**：Q&A1件ごとに `---` の区切り線が入っているため、1件が1チャンクになります（69チャンク、最長526文字）。旧環境は `\n` で、質問と回答が別チャンクに分かれていました（448チャンク、平均23文字）。`\n\n` も見出しと本文の間の空行で分かれるので不向きです。
- **ソリューション資料（`## `）**：「概要」「対応ニーズ」などの見出しごとに1チャンクになります。「原文抽出」の項目は1024文字を超えるので、さらに分割されます。`## ` は `### ` にも一致するため、原文抽出の中はページごとに分かれます。

保存する前に「チャンクをプレビュー」で、狙いどおりに分かれているかを確認してください。
